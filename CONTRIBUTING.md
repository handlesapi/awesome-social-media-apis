# Contributing to Awesome Social Media APIs

Thanks for improving the list. It is meant to be useful and neutral: an entry earns its place by being good, not by who maintains it.

## Add an entry

An entry should be:

- **Real and live.** The link returns a page today. We check links before merging.
- **About social media data or building on it:** a platform's official API, a client library, a hosted data API, or a relevant spec or tool.
- **Described in one plain sentence** that says what it is, with no superlatives and no marketing language.
- **Placed alphabetically** in the right section.

One entry per pull request line, in this form:

```
- [Name](https://example.com/) - What it is, in one sentence.
```

## Third-party data APIs

These are listed on the same terms as every other provider, including Handles API. State only facts you can verify (platforms covered, whether it is free or paid). Pricing claims go stale, so link to the pricing page instead of quoting numbers.

## Not accepted

Dead or paywalled-only links, link shorteners, duplicates, tools whose main purpose is evading a platform's protections or sending spam, and anything that cannot be described neutrally.

Fixes (a moved URL, a wrong description) are welcome without discussion. Issues: [handlesapi/awesome-social-media-apis/issues](https://github.com/handlesapi/awesome-social-media-apis/issues).
